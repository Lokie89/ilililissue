# 샘플 프로젝트 도메인 정책

이 문서는 하네스 검증용 샘플 도메인 정책이다.

## 개념

### Badge

- 정의: 사용자에게 표시되는 라벨 또는 업적을 나타내는 후보 개념이다.
- 상태: 미정
- 생명주기: 미정
- 정책: 부여 주체, 제거 가능 여부, 중복 허용 여부는 아직 결정되지 않았다.
- 불변 조건: 미정
- 관련 개념: User
- 결정되지 않은 질문:
  - Badge는 단순 표시 라벨인가, 업적인가, 권한인가?
  - Badge는 사용자가 직접 선택할 수 있는가?
  - Badge는 한 사용자에게 여러 개 부여될 수 있는가?

## 정책

- 위 미결 질문이 해결되기 전에는 Badge를 코드 모델로 확정하지 않는다.
- DB 구조는 Badge의 도메인 의미가 확정된 뒤 설계한다.
