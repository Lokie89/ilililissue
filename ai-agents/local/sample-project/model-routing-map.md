# 샘플 프로젝트 모델 라우팅 매핑

이 문서는 Codex와 Claude를 같은 프로젝트에서 함께 쓸 때 두 모델의 작업 난이도 판단 기준을 맞춰보는 선택적 문서의 작성 예시다. 실제 모델 ID는 계정/제품 표면에 따라 달라지므로 이 샘플에는 넣지 않는다.

## 매핑 표

| 작업 난이도 | Claude 별칭 | Claude 추론 강도 | Codex 등급(문서 용어) | 비고 |
| --- | --- | --- | --- | --- |
| 단순 | `haiku` | `low` | 단순 | 파일 탐색, 반복 정리 |
| 일반 | `sonnet` | `medium` | 일반 | 범위가 명확한 구현, 문서 수정 |
| 복잡 | `opus` | `high` | 복잡 | 설계, 도메인 정책, 복잡한 디버깅과 리뷰 |
| 고위험 | `opus` | `xhigh`~`max` | 고위험 | 보안, 데이터 삭제·마이그레이션, 되돌리기 어려운 변경 |

## 실제 모델 ID

- 이 샘플 프로젝트는 실행 코드가 없으므로 실제 모델 ID를 기록하지 않는다.
- 실제 프로젝트에 적용할 때는 이 표 아래에 계정/제품 표면에서 지원하는 실제 모델 ID와 `.codex/agents/*.toml` 설정을 채운다.

## 결정되지 않은 질문

- 없음(샘플 문서이므로 실제 프로젝트에 적용할 때는 이 문서 전체를 프로젝트 값으로 교체한다).
