# legacy-module 서브트리 오버라이드 예시 (Codex)

이 디렉터리는 중첩 `AGENTS.md`로 서브트리 전용 예외를 두는 방법을 보여주는 샘플이다. 실제 코드는 없다.

## 적용 순서

1. 루트 `AGENTS.md`
2. `global/models/codex/AGENT.md`와 나머지 글로벌 Codex 문서
3. `local/sample-project/`의 goal/도메인/도구/검증 문서
4. 이 파일 — `legacy-module/` 안에서 작업할 때만 위 규칙을 보완하거나 재정의한다

## 이 디렉터리의 예외 (가상 예시)

- 이 모듈은 폐기 예정 레거시 코드로 가정한다. 새 기능 추가나 광범위한 리팩터링은 하지 않고, 버그 수정만 최소 범위로 적용한다.
- 예외 이유: 곧 삭제될 예정이라 유지보수에 추가 투자를 하지 않기로 결정했다(샘플 문서이므로 실제 결정은 아니다).
- 이 예외는 `legacy-module/` 안에서만 적용되며, `local/sample-project/`의 나머지 부분에는 적용되지 않는다.

## 실제 프로젝트에 적용할 때

- 이 파일 전체를 실제 서브트리 예외 내용으로 교체한다.
- 예외 이유가 없는 오버라이드는 만들지 않는다(`global/models/codex/AGENT.md`의 "글로벌과 로컬" 규칙).
