# 샘플 프로젝트 도구 정책

이 문서는 하네스 검증용 샘플 프로젝트의 도구 정책 예시다. 실행 가능한 코드가 없으므로 대부분 항목은 해당 없음으로 남긴다.

## 사용할 수 있는 도구

- 파일 검색: `Glob`/`Grep`(문서 구조 확인)
- 파일 확인: `Read`
- 코드 변경: 해당 없음(실행 코드가 없는 문서 전용 샘플)
- 검증: `bash scripts/validate-docs.sh`(저장소 루트 기준)

## 프로젝트 명령

| 목적 | 명령 | 비고 |
| --- | --- | --- |
| 설치 | 해당 없음 | 실행 가능한 코드가 없다 |
| 실행 | 해당 없음 | 실행 가능한 코드가 없다 |
| 테스트 | 해당 없음 | 실행 가능한 코드가 없다 |
| 빌드 | 해당 없음 | 실행 가능한 코드가 없다 |
| 린트 | 해당 없음 | 실행 가능한 코드가 없다 |

## 승인 필요한 작업

- 네트워크 설치: 해당 없음
- 권한 상승: 해당 없음
- 외부 서비스 호출: 해당 없음
- 데이터 삭제 또는 마이그레이션: 해당 없음

## 금지된 작업

- 비밀값 출력 또는 저장
- 사용자 승인 없는 파괴적 명령
- 관련 없는 파일 포맷팅
- 미결 상태인 `Badge` 개념을 코드나 DB 구조로 임의 확정하는 것

## 결정되지 않은 질문

- 이 샘플에 실제 실행 코드를 추가할지 여부(현재는 문서 구조 예시 용도로만 유지한다).
