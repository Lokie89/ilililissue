# 샘플 프로젝트 아키텍처 청사진

이 문서는 로컬 프로젝트별 아키텍처 청사진 작성 예시입니다.

## 작성 원칙

- 샘플 프로젝트는 실행 가능한 실제 서비스가 아니라 하네스 예시다.
- 확정되지 않은 기술 결정은 `미정` 또는 `해당 없음`으로 둔다.
- 도메인 정책 예시는 `domain-policy.md`에 두고, 이 문서는 기술 구조와 운영 전제를 설명한다.
- 외부 연동 어댑터, API, 메시지, 파일 교환이 있으면 인터페이스 문서 위치와 계약을 남긴다.

## 프로젝트 형태

- 유형: 문서/하네스 예시
- 주요 배포 단위: 해당 없음
