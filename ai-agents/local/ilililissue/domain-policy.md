# 도메인 정책

이 문서는 ilililissue의 실제 도메인 정책을 정의합니다. 근거는 [기획 원문](./docs/planning-2026-10-28.md)과 2026-10-28 사용자 결정입니다.

## 확정된 결정 (2026-10-28)

| 항목 | 결정 |
| --- | --- |
| 비회원 범위 | 이슈 열람만 허용. 투표·의견·추천·신고는 로그인 필요 |
| 작성자 표시 | 닉네임 |
| 결과 공개 | 해당 이슈에 투표한 회원에게만 투표 비율과 의견 목록 공개 |
| 입장 변경 | MVP에서 불가 |
| 의견 정렬 | 추천 기능 제공, 추천순·최신순 정렬 지원 |
| 이미지 | MVP에서 이슈 이미지 미사용. 자체 요약 + 원문 링크 |

## 개념

### Member (회원)

- 정의: 서비스에 가입한 사용자.
- 상태: 활성. (탈퇴·정지는 미정)
- 정책: 이메일과 비밀번호로 가입한다. 닉네임은 의견 작성자 표시에 쓰인다.
- 불변 조건: 이메일은 유일하다. 닉네임은 유일하며 2~12자(가안)다. 비밀번호는 해시로만 저장한다.
- 역할: `USER`, `ADMIN`.
- 결정되지 않은 질문: 탈퇴 시 의견 처리, 닉네임 변경 허용 여부, 이메일 인증 여부.

### Issue (이슈)

- 정의: 관리자가 자체 작성한 중립 질문과 배경 설명, 원문 출처로 구성된 토론 주제.
- 상태: `DRAFT`(작성 중) → `REVIEWED`(정확성·편향성·저작권 검수 완료) → `PUBLISHED`(게시) → `CLOSED`(투표 마감, 미정).
- 정책: 관리자만 생성·수정한다(권한 검증은 보안 설정에서 `/api/admin/**` 경로를 `ADMIN`에게만 허용하는 방식으로 한다). 비회원 포함 누구나 `PUBLISHED` 이슈를 조회한다. 카테고리를 1개 가진다. 제목은 100자, 배경 설명은 1000자 이하(가안)다.
- 수정: `DRAFT`, `REVIEWED` 상태에서만 내용을 수정할 수 있고, 수정하면 `DRAFT`로 돌아가 다시 검수가 필요하다.
- 불변 조건: 출처(IssueSource)가 1개 이상이어야 `PUBLISHED`가 될 수 있다. 상태는 정해진 순서로만 전이한다.
- 정정: `PUBLISHED`, `CLOSED` 상태에서 배경 설명만 정정할 수 있고 정정 시각을 남긴다.
- 결정되지 않은 질문: 투표 마감 시점(`CLOSED` 전이 조건), 게시 후 질문 문구 수정 허용 범위.

### IssueSource (이슈 출처)

- 정의: 이슈의 근거가 된 원문 기사 링크.
- 정책: 원문 URL, 언론사, 발행일을 가진다. 기사 본문·사진은 저장하지 않는다.
- 불변 조건: URL은 http/https 형식이다. 한 이슈 안에서 URL은 중복되지 않는다.

### Category (카테고리)

- 정의: 이슈 분류 (예: 경제, 사회, 생활).
- 정책: 관리자가 관리한다. 목록은 운영 데이터로 관리한다.

### Stance (입장)

- 정의: `AGREE`(찬성), `NEUTRAL`(중립), `DISAGREE`(반대).

### Vote (투표)

- 정의: 회원이 이슈에 대해 선택한 입장.
- 정책: 회원당 이슈별 1회. MVP에서는 변경·취소 불가. `PUBLISHED` 이슈에만 투표할 수 있다.
- 결과: 입장별 투표 수와 비율(소수 첫째 자리 %)을 투표한 회원에게만 공개하고, "서비스 참여자 기준 결과" 고지를 함께 응답한다. 마감된 이슈도 투표자는 결과를 볼 수 있다.
- 불변 조건: `(issueId, memberId)` 유일.

### Opinion (의견)

- 정의: 투표한 회원이 남기는 독립된 의견 글. 다른 의견에 대한 답글이 아니다.
- 정책: 해당 이슈에 투표한 회원만 작성한다. 회원당 이슈별 1개. 수정은 최대 1회. 의견의 입장은 투표 입장과 같다.
- 불변 조건: `(issueId, memberId)` 유일. 내용은 공백일 수 없고 길이 제한이 있다. 작성자만 수정한다.
- 표시: 입장별 탭으로 나눠 추천순 또는 최신순으로 보여주며 작성자 닉네임을 표시한다. 숨김 처리된 의견은 노출하지 않는다.
- 결정되지 않은 질문: 내용 최대 길이(가안 500자), 작성자 본인 삭제 허용 여부.

### Recommendation (추천)

- 정의: 회원이 의견에 표시하는 공감. 비추천은 없다.
- 정책: 해당 이슈에 투표한 회원이 의견당 1회 추천한다(의견 목록이 투표자에게만 공개되므로 같은 기준을 적용). 숨김 처리된 의견은 추천할 수 없다. 자기 의견 추천은 미정이라 현재 막지 않는다.
- 불변 조건: `(opinionId, memberId)` 유일.
- 결정되지 않은 질문: 추천 취소 허용 여부, 자기 의견 추천 허용 여부, 다른 입장 의견만 추천 가능한지 여부. 기본 정렬(추천순/최신순).
- 메모: 기획 원문은 좋아요·싫어요를 MVP에서 제외했으나 2026-10-28 사용자 결정으로 추천(단방향)만 MVP에 포함한다.

### Report (신고)

- 정의: 회원이 부적절한 의견을 관리자에게 알리는 것.
- 상태: `RECEIVED` → `RESOLVED_HIDDEN`(의견 숨김) 또는 `RESOLVED_DISMISSED`(기각).
- 정책: 회원당 의견별 1회. 관리자가 처리한다. `RECEIVED` 상태에서만 처리할 수 있다. 숨김 처리 시 해당 의견도 숨긴다.
- 사유: 사유 목록이 정해지기 전까지 300자 이하 자유 입력(가안).
- 결정되지 않은 질문: 신고 사유 목록, 누적 신고 시 자동 숨김 여부.

### ParticipationEvent (참여 이벤트)

- 정의: 참여 지표 측정용 운영 로그 (이슈 조회, 투표, 의견 작성, 입장 탭 열람).
- 정책: 반대 의견 열람률 측정을 위해 회원의 투표 입장과 열람한 탭 입장을 함께 기록한다.
- 결정되지 않은 질문: 비회원 방문 식별 방식(익명 쿠키 등), 보관 기간.

## 결정되지 않은 질문 (공통)

- 다중 계정 조작 탐지 기준
- 개인정보 처리방침과 탈퇴 시 데이터 처리
