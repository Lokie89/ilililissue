# Claude 모델

Claude 모델은 Claude Code 하네스(에이전트 CLI, Plan Mode, 서브에이전트, Skill, Workflow) 위에서 코드베이스를 읽고, 필요한 변경을 직접 구현하고, 검증 결과를 남기는 개발 작업용 에이전트입니다.

사람이 이 모델의 목적과 문서 구성을 빠르게 이해하기 위한 문서입니다. 에이전트가 실제 작업 전에 읽어야 하는 실행 기준은 [AGENT.md](./AGENT.md)에 있습니다.

## 핵심 원칙

- 청사진, 계획, 설계만 요청받으면 Plan Mode로 먼저 계획을 제시하고 실행하지 않습니다.
- 도메인 개념이 추가되면 도메인 정책을 가장 먼저 확인합니다.
- 프로젝트별 규칙이 없으면 필요한 대화를 통해 로컬 하네스를 만든 뒤 진행합니다.
- 도메인 모델과 데이터베이스 모델을 분리해서 봅니다.
- 역할에 맞는 서브에이전트와 모델 별칭을 사용합니다.
- 되돌리기 어렵거나 공유 상태에 영향을 주는 행동은 실행 전 사용자 확인을 받습니다.
- 작업 범위 안에서 사용하지 않는 코드는 정리합니다.
- 변경 후 가능한 검증을 실행하고 결과를 남깁니다.

## Claude Code 시스템 규칙과의 관계

이 문서 세트는 Claude Code에 이미 내장된 시스템 규칙(권한 프롬프트, 파괴적 작업 확인, hook, Plan Mode 동작)을 대체하지 않고 보완합니다. 이 문서와 Claude Code 내장 규칙이 충돌하면 내장 규칙이 우선합니다.

## 기본 운영 원칙

Claude는 먼저 저장소의 현재 상태를 읽고, 기존 패턴을 따른 뒤, 최소 범위의 변경으로 목표를 달성합니다. 변경 후에는 가능한 검증을 실행하고, 실행하지 못한 검증은 이유를 기록합니다. 다른 모델(예: [Codex](../codex/README.md))과 같은 저장소를 공유할 때는 `global/`의 공통 전제를 따르되, 모델별 실행 세부사항은 각자의 `global/models/<model>/`에 둡니다.
